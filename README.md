# Creative Making Term 2 课程笔记与项目

> 技术栈：Arduino、Unity(C#)、TouchDesigner ｜ 2026 年春季学期

## 内容概览

这里是我在伦敦艺术大学 Creative Making 课程第二学期的学习笔记与项目，包含两个 Sprint、一个期末研究项目，以及各周课堂笔记。

## 项目导航

- **Sprint 1：手势俄罗斯方块（Arduino + Unity）**
  - 用 Arduino UNO R4 与 APDS-9960 手势传感器，配合 Unity(C#) 打造无接触交互版俄罗斯方块，让肢体动作本身成为玩法；
  - 完成硬件选型与固件，解决 Arduino 与 Unity 之间的串口通信瓶颈，修复方块越界、按位置生成音符等问题；
  - 详见 `Sprint 1.md`，代码见 `Sprint 1 Arduino Code/` 与 `Sprint 1 Unity Code/`。
- **Sprint 2**：见 `Sprint 2.md`。
- **期末研究项目：Where Light Shatters**：见 `Final Research Project/`，一个“会拒绝、会受伤、会反抗”的手势交互生态。
- **各周笔记**：`Week 1 notes.md` 至 `Week 9 notes.md`。

## 如何查看

直接按上方导航打开对应 Markdown 与代码文件夹即可；Arduino 固件与 Unity 工程分别在对应目录中。
